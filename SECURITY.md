# Security policy

## Reporting security issues

Sent takes security seriously. If you believe you have found a vulnerability in this SDK or in the Sent Voice service it talks to, report it to support@sent.dm before disclosing it anywhere else.

Include what you found, how to reproduce it, and the SDK version. You'll get an acknowledgement, and we'll keep you informed while we investigate and fix it.

## Responsible disclosure

Give us a reasonable amount of time to investigate and address the issue before making any information public. We won't take action against researchers who report in good faith and follow this policy.

## Supported versions

Security fixes ship in the latest release of `sentdm-voice-agents`. Upgrade to the latest version to receive them.
